### 4.2 Repeterbar KI-arbeidsmodell

1. Clarify the decision/operational problem.
2. Assemble and structure relevant context.
3. Define source precedence, assumptions, constraints and prohibited shortcuts.
4. Decompose work into inspectable stages/artifacts.
5. Delegate bounded analysis, implementation, review or documentation.
6. Require tests, reconciliation, citations, proof or explicit uncertainty.
7. Review exceptions, stale state, logic drift and unresolved risk.
8. Translate output into a stakeholder-appropriate deliverable.
9. Preserve handoff context for the next human/agent.
10. Stop when mandatory coverage and quality thresholds pass.

For high-impact or externally consequential actions, preserve a human decision point and an auditable handoff. This is a workflow principle, not evidence of a formal enterprise AI-governance role.

### 4.3 Konkret evidens

The active forecasting workspace demonstrates a persistent operating structure for coding agents:

- project instructions defining scope, constraints, proof requirements and prohibited actions;
- separation among agent-operation files, source repository and generated dependencies;
- truth precedence prioritizing current files/tests over narrative memory;
- run initialization, compact patch logging and finish-state recording;
- run state, process logs, issue register, archives, handoffs and plans;
- helper tooling and targeted tests for handoff;
- domain invariants, including horizon-safe training and prohibition of silent feature drops;
- separation of local/synthetic validation from unvalidated live-database/model execution;
- non-destructive repository constraints.

The defensible ownership claim concerns architecture, orchestration, automated components, integration, review, validation and human accountability. Implementation is distributed among Vegard, coworker and AI/coding agents.

Registrert KI-superbrukerrolle og beskrevet Teams-bistand: se Work_experience.md §1.1 (EMP-OUS-010).

### 4.4 Trygge KI-påstander

- Designs structured human-governed AI workflows with explicit scope, source hierarchy, constraints, stages, artifacts, acceptance criteria and stopping rules.

## 6. Overførbare styrker, arbeidsstil og selvkalibrering

### 6.1 Systemtenkning og kompleksitetsreduksjon
